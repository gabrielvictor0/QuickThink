# QuickThink

Trabalho de Conclusão do Curso Técnico em Desenvolvimento de Sistemas. 

### O que é o projeto e como surgiu sua idealização?

O QuickThink é um sistema web de uso interno para gerenciamento de soluções técnicas que nasceu de uma parceria entre a Escola SENAI de Informatica Paulo Antonio Skaf e a CTI, uma empresa consolidada no mercado de tecnologia brasileiro atuando nas áreas de conectividade, cibersegurança e cloud. Mesmo com seus 30 anos de atuação, a empresa convivia com a dor de não conseguir armazenar informações valiosas de chamados técnicos. Para resolver este problema a CTI contatou a Escola SENAI de Informática, a qual disponibilizou seus alunos para desenvolver um sistema que solucionasse seus problemas.

### Divisão de tarefas

Tarefas Back-End: 
- CRUD
- Autenticação de usuário
- Integração da Inteligência Artificial Gemini
- Persistência de dados no SQL server através do ORM Entity Framework
- Configuração e integração do armazenamento de imagem no Blob Storage da Azure

Tarefas Front-End: 
- Requisições HTTP para a API 
- Estrutura HTML e estilização CSS dos componentes
- Configuração de rotas
